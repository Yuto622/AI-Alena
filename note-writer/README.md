# note-writer

note の記事を「書く → 予約 → 公開 → 売上の記録 → 次のテーマ選び」まで回すシステム。管理画面つき。

## 全体の流れ（初期設定で全自動）

1時間ごとの**予約実行**（`/cron/tick`）が、次をすべて自動で行う。

1. 期限の来た「公開OK」の記事を、Playwright で note に**公開**する
2. 公開予定が3本を下回ったら、**ネタ帳**（`topics.json`）のテーマから Claude が記事を書く。売れたタグを多く含むテーマが先
3. ネタ帳が空になったら、Claude が**新しいテーマ**を考えて足す
4. 書いた記事を Claude が**自動チェック**する（筆者の経験にないことを書いていないか、事実の誤り、有料部分の中身など）
5. 通った記事は月・水・金 20:00（日本時間）の空いている枠に「公開OK」で**予約**される。通らなかった記事は下書きで止まり、枠は空けたまま

人が手を入れるのは、note の管理画面の販売数・閲覧数を月ごとに入力するところだけ（note に売上を取り出す API がないため）。入力しなくても回り続けるが、その場合はテーマ選びに売上が反映されない。

止まる仕組み：
- 公開に失敗した記事は「失敗（要確認）」になり、人が直すまで再実行しない（note に下書きが増え続けないため）
- 生成は1日2本まで（自動チェックで止まり続けても費用が増えない）
- 設定で「自動生成」「自動で公開OK」をそれぞれ切れる

## デプロイ（Google Cloud）

```bash
gcloud auth login
bash note-writer/deploy.sh <GCPプロジェクトID>
```

初回だけ note のメールアドレス・パスワード・Anthropic API キーを聞かれる（画面には表示されない）。
最後に管理画面の URL とパスワード（ユーザー名 `admin`）が表示される。2回目以降も同じコマンドで更新できる。

### 固定費をほぼゼロにする構成

| 部品 | 設定 | 費用の目安 |
|---|---|---|
| Cloud Run | 最小0台・最大1台、リクエスト中だけ課金 | 無料枠内 |
| Cloud Storage | データ置き場（数MB）、us-central1 | 無料枠内 |
| Cloud Scheduler | 1ジョブ（毎時5分） | 無料（3ジョブまで） |
| Secret Manager | 5件 | 無料（6件まで） |
| Artifact Registry | 最新のイメージ1つだけ残す | 数十円/月 |
| Claude API | Claude Haiku 5.5（一番安いモデル）。記事1本あたり1円前後 | 使った分だけ（固定費ではない） |

無料枠の条件は Google Cloud の料金ページで確認すること。

## ローカルで動かす

```bash
cd note-writer && npm install
ADMIN_PASSWORD=好きな文字 CRON_TOKEN=好きな文字 node server.mjs   # http://localhost:8080
node publish.mjs --check                                            # note のログイン確認
node publish.mjs articles/xxx.md --draft                             # 下書き保存まで
```

## 記事ファイル

`articles/*.md`。先頭のメタ情報：

```
---
title: タイトル
price: 500            # 0 なら無料
tags: [海外大学, 勉強法]
status: draft         # draft / ready / published / error
publish_at: 2026-11-04T11:00:00.000Z
account: default      # uspeak なら NOTE_USPEAK_EMAIL / NOTE_USPEAK_PASSWORD を使う
cta: uspeak           # cta/uspeak.md を記事の最後に付ける（任意）
---
```

`<!-- paid -->` の行より下が有料部分。表は note が対応していないので使わない。

## 先に設定すること

- 管理画面の「設定」→「筆者について」：記事に経験として書いてよいことだけを書く。生成された記事はここ以外の経験を書かない
- 自動生成・自動公開は初期状態でオン。止めたいときは設定で外す
- note の画面のボタン名・入力欄は推測で作っている。最初の公開は「note に下書き保存」で試し、「実行ログ」の画面で確認する

## 広げる仕組み（管理画面の「SNS・LINE・ブログ」）

- **マガジン・メンバーシップ**：note で作ったマガジンやメンバーシップの名前を書くと、公開するときに自動で入れる（`paid 名前` / `free 名前` / `all 名前`）
- **あわせて読みたい**：記事の最後に、同じタグの過去の記事を3本付ける
- **Threads**：公開時に紹介し、1日1回、過去の記事を再紹介する（無料の Threads API。自分のアカウントだけなので審査なし。トークンは7日ごとに自動延長）
- **LINE**：週1回、その週に公開した記事を友だち全員に送る（無料プランは月200通。足りなければ見送る）。友だち追加の URL を入れると、全記事とブログの最後に案内が付く
- **ブログ**：公開した note 記事を検索向けに書き直して `/blog` に載せる（有料記事は無料部分だけ）。登録したアフィリエイトは合う記事にだけ入れ、「PR」を表示する。`/sitemap.xml` を Google Search Console に登録する
