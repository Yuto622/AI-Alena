note 管理画面

売上を伸ばすための提案

    公開予定

    記事ごとの売上

    毎日1回、note のダッシュボードから閲覧数・販売数を自動で取り込みます。取り込めなかった数字は手で直せます。

    見出し画像の見本を開く

    ネタ帳

    売れたタグを多く含むテーマから先に生成されます。

    話題枠（バズ枠）

    毎朝、note の「急上昇」「注目キーワード」を読み、英語・海外・英語学習に自然につなげられる話題があれば「話題 × 英語」の無料記事を書いて、その日の昼に公開します。つながる話題がなければ書きません。週の本数と時刻は「設定」で変えられます。

    紹介するアプリ・商品

    記事ごとに、読者に合うものを AI が選んで記事の最後で紹介します。合うものがなければ何も付けません。合うものが複数あるときは、2割の記事で載せた回数の少ないものを試してデータを集めます。リンクは自分のサーバーを経由させて、クリックを数えます。
    「法人向け」は、教室の方には説明の予約へ、保護者の方には「通っている教室の先生に伝えてください」と案内します（教室を飛ばして売りません）。「個人向けサービス」は支払いページへ案内し、予約ページは支払ったあとに見せます。

    まとめて登録（JSON を貼る）

    [{"name": "...", "kind": "service", "url": "https://...", ...}, ...] の形で貼ると、今の一覧の後ろに足します。

    これまでの学び（週1回、実績から自動でまとめ直す）

    
      
    
    
    
  
    

  
    
    
    note のマガジン・メンバーシップに自動で入れる
    
      
    先に note で、マガジン（またはメンバーシップのプラン）を作っておきます。公開するとき、名前の行の「追加」を自動で押します。1行に1つ：「paid 名前」（有料記事だけ）／「free 名前」（無料記事だけ）／「all 名前」（全部）。名前は note と一字一句同じに。
    
      
      
      
    
    
    

    
    Threads への自動投稿（無料）
    
      
    
      
    公開したら紹介を1回、さらに1日1回、よく読まれた・売れた過去の記事をもう一度紹介します（同じ記事は14日あける）。
    
      
    アクセストークンの取り方（初回だけ・15分）
      
        
    1. Meta for Developers にログイン →「アプリを作成」→ ユースケースで「Threads API にアクセス」を選ぶ
      2. 
        
    2. アプリの「ユースケース」→ Threads API →「アクセス許可」で threads_basic と threads_content_publish を追加
      3. 
        
    3. 「アプリの役割」→「役割」→「Threads テスター」に自分の Threads アカウントを追加し、Threads アプリの「設定 → アカウント → ウェブサイトのアクセス許可 → 招待」で承認
      4. 
        
    4. ユースケースの「設定」にある「ユーザートークン生成ツール」で自分のアカウントのトークンを作り、下に貼る（審査は不要です。自分のアカウントにだけ投稿するため）
      5. 
      
    トークンは60日で切れますが、このシステムが7日ごとに自動で延長します。
