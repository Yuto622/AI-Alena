# U-Space × U-Speak 営業の型（写像表）

U-Speak Roblox で動いている営業パイプラインを、U-Space でどう使うか。
**変える部分は「商品名・単価・刺さりの一言」だけ**。工程・ツール・担当は変えない。

| 工程 | U-Speak Roblox（現状） | U-Space での差分 | 使うスキル／資産 |
|---|---|---|---|
| ① リスト | Knocklist 購入 → 英語×子ども×小学生以上に精査（歩留まり15%） | 同じ条件。**学習塾・民間学童を追加**（`KODOMO` 条件に「学童／アフタースクール／放課後」を足す） | knocklist-vetting |
| ② DM | サードパーティー入稿（代表者名「様」でアポ率+2%） | 原稿を宇宙版に差し替え。見出し「小学生が、英語で、宇宙の年齢を測る。」 | dm-list-builder |
| ③ 架電 | EMA 委託 | トークに「UCLAの研究者が監修」「先生に宇宙知識は不要」の2点を追加 | — |
| ④ 商談準備 | 先方サイトをリサーチ → 刺さりマップ PDF | 刺さりマップに「理科・探究・STEAM への言及有無」列を追加 | uspeak-meeting-prep-research |
| ⑤ 提案書 | pptx 20枚 + ROI 3モード | スライド差し替え：実機画像を U-Space（ISS/Hubble Lab/レポート）に。ROI 式は `content/pricing.ts` と一致 | uspeak-proposal-builder |
| ⑥ 契約 | LaTeX 契約書ドラフト | サービス名・単価の差し替えのみ | uspeak-proposal-builder（contract） |
| ⑦ 請求 | 月額 × 人数、US-年-番号 | 品目「U-Space 月額利用料」を追加。既存校は同じ請求書に1行 | uspeak-invoice |
| ⑧ 運用 | 運用マニュアル／開発者マニュアル | 章を追加（教室コード・投影モード・レポート出力） | operations-documentation |

## 価格規律（U-Speak と共通）
- 初3ヶ月 ¥800/名は**キャンペーン**として明示。4ヶ月目以降の標準単価を提案書に必ず書く。
- ¥800 より下げない。値引き要請は「¥800 期間を最大6ヶ月に延長」「出張体験会1回無料」で返す。
- 1校目（ツリーベル様）には「U-Space 1校目導入パートナー」として Plus を ¥800 で 3ヶ月、事例化の同意と引き換えに。

## 商談の一言（業態別）
- 英会話教室：「英語の“何を話すか”を、毎週こちらが用意します。発話量が数字で保護者に届きます。」
- 学習塾：「採用ゼロで、理科×英語の探究コースを来月開講できます。」
- 学童：「スタッフの誰でも45分回せる、本物の宇宙クラスです。」
- U-Speak 既存校：「同じ教室コード、同じ請求書に1行足すだけです。」

## 想定問答
| 懸念 | 返し |
|---|---|
| 英語教室で理科をやる意味は？ | CLIL（内容言語統合）は欧州の標準。語彙は英検級に合わせ、テーマが「話す理由」になる。 |
| 先生が宇宙を知らない | 45分台本・投影モード・クイズ解説を用意。難問は「UCLAに聞く」に送れる。 |
| 8週で終わったら？ | 半年ごとに第2・第3タームを追加（太陽系探査・宇宙開発史・地球観測）。 |
| タブレットがない | 投影モード＋紙のワークシート（Data Lab の計算は電卓で可）。生徒端末は Speaking のみ必須。 |
| 保護者に直接売らないの？ | 売らない。教室の自校コースとして月謝・オプション設計を任せる。 |

## スコープ規律（単独商談時）
U-Speak と同じ。「やります／無料で追加します」は言わない。「技術的には可能。優先順位と契約条件は別途」で返し、24時間以内に「ご要望対応表」を送る。
