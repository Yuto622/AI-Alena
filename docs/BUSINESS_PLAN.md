# U-Space 事業計画書（v0.1 / 2026-11-07）

合同会社 U-Speak Lab　第2プロダクト
「宇宙探究 × 英語」の8週カリキュラムを、英会話教室・学習塾・民間学童に BtoB SaaS で提供する。

---

## 0. 結論（30秒）

- **何を売る**：先生に宇宙知識ゼロで回せる「週1・45分の宇宙×英語クラス」一式（教材・AI管制官・Data Lab・台本・保護者レポート）。
- **誰に売る**：U-Speak Roblox と**同じ買い手**（子ども英語教室・塾・学童の経営者）。保護者直販はしない。
- **いくらで**：生徒1名 月額 ¥1,500〜3,500（税別）、初3ヶ月 ¥800、最低10名。U-Speak と同じ価格構造。
- **なぜ勝てる**：①需要は実証済み（STEM習い事・探究）②供給ゼロ（月謝制の宇宙塾も教室向け宇宙CLIL教材も無い）③UCLA天文物理の現役研究者という看板は模倣不能④営業の型・請求・マニュアルが既にある。
- **どれくらい儲かる**：粗利 ≈ 95%。50校・1,500名で年商 約¥2,700万、CAC回収 1〜2ヶ月（§6）。

## 2. プロダクト

### 2.1 生徒体験（週1・45分、タブレット1台/人）
1. **Briefing**：英文6文（英検5-4級 / 3級の2版）＋日本語トグル＋読み上げ
2. **Words**：8語・3レベル・例文・発音
3. **Data Lab（異次元の核）**
   - 🌍 **School → Space メタバース**：住所から御校の街を衛星写真＋標高で3D生成。そこから打ち上がり、地球を見下ろし、本物の位置のISSまで飛ぶ。U-Speak Roblox の「①教室専用ワールド」を手作業の3D化から**住所入力だけの自動生成**に置き換え、地形を Roblox に書き出せる
   - 📍 **御校の上空**：教室の住所を入れるだけで、ISSが御校の真上を通る日時・方角・肉眼で見える時間帯（TLE＋SGP4で7日分）、今この瞬間の距離、日の出入り、NASA/ESAの衛星写真が教材に。「この日の夜、南西の空を見上げる」宿題が毎週出せる＝家庭に持ち帰る会話のネタ
   - 🛰️ ISS ライブ位置（5秒更新）→「1日に何周？」を計算
   - 🌙 今夜の月齢を計算 →「次の満月まで何日？」
   - 🪐 トランジットシミュレータ：惑星サイズで減光 1% / 0.01% を作る（Kepler の実法）
   - 🌌 **ハッブル・ラボ**：実在7銀河団の距離・速度に直線を合わせ H₀ → 宇宙の年齢を自分で求める（UCLA Astro 117 の演習を小学生版に）
   - 🧮 数値ラボ：火星までの電波遅延、いて座A*の半径、ISSの1分の移動距離
4. **Quiz**：6問・解説つき（解説が学び）
5. **Speaking**：AI管制官「Commander」と英語で音声会話（ブラウザ音声認識＋TTS）→ 1〜5点フィードバック
6. **Ask a UCLA astrophysicist**：質問を貯め、月1ライブで代表が回答（1対多でスケール）

### 2.2 先生体験（宇宙知識ゼロ前提）
- 設定は「住所を入れるだけ」。以後、全ミッションが御校基準の上空データになる
- 45分進行台本、投影モード（大画面・1文ずつ）、出典つき「今日の数字」
- 生徒別の完了・クイズ・発話語数、CSV出力（既存のスプレッドシート運用に接続）
- **保護者向けAIレポート**：「お子さんが測った宇宙の年齢：14.0 Gyr」が載る → 月謝納得感・退会防止
- 修了証（教室名・代表名入り、印刷）

### 2.3 技術
Vite + React + TypeScript / Express / Gemini（無い時はルールベース）/ JSON ストア → Firestore。Cloud Run 1コンテナ。詳細は ARCHITECTURE.md。

## 5. なぜ真田がやる意味があるか（模倣困難性）

1. **監修者＝現役の天文物理研究者**：Hubble Lab は本人が大学で解いた演習の再設計。教材会社は「本物の銀河団データで子どもに H₀ を出させる」発想も検証力も持たない。
2. **月1「UCLA研究者に聞く」ライブ**：代表本人が登壇。1対多で全校に配信でき、限界費用ゼロで差別化が続く。競合が同じものを出すには同じ経歴の人間が必要。
3. **制御理論×AI の技術力**：AI管制官・自動レポート・教室コード運用は U-Speak Roblox で実装済み。開発を外注せず、要望に当日対応できる。
4. **BtoB の営業資産**：Knocklist 精査→DM入稿→架電→商談準備PDF→提案書pptx→契約書→請求書の全工程がスキル化済み。買い手も同じなので**既存リスト・既存顧客にそのまま流せる**。
5. **ブランドの一貫性**：「U-Speak（話す）→ U-Space（宇宙）」。既存顧客にとって“同じ会社の新コース”。

## 6. 収益モデル（単位経済）

### 6.1 1校あたり
- 想定：30名 × Plus ¥2,500 ＝ **月 ¥75,000**（初3ヶ月は ¥24,000）
- 年間売上/校 ≈ ¥24,000×3 + ¥75,000×9 ＝ **¥747,000**
- 限界費用：Gemini API ≈ ¥5〜15/生徒/月、ホスティング ≈ ¥2,000/月/全体 → **粗利 ≈ 95%**

### 6.2 CAC（U-Speak の実測値ベース）
- Knocklist 購入リストの歩留まり 約15%、代表者名つきDMでアポ率 +2%、架電は EMA 委託。
- 1波：DM 500通（¥150/通 = ¥75,000）＋架電 ¥100,000 → アポ 12〜15件 → 契約 3〜4校
- **CAC ≈ ¥45,000〜60,000/校** → 初3ヶ月の売上（¥72,000）で回収。**回収 1〜2ヶ月**。

### 6.3 スケール
| 校数 | 生徒数 | 年商（Plus 中心・4ヶ月目以降ベース） |
|---|---|---|
| 10校 | 300名 | ¥9.0M |
| 50校 | 1,500名 | **¥45M** （保守的に Standard 混在で ¥27M） |
| 150校 | 4,500名 | ¥135M |

既存 U-Speak 顧客へのクロスセルは CAC ≈ 0。1校目はツリーベル様に Plus を 3ヶ月 ¥800 で提案し、事例を作る。

### 6.4 リスクと対処
| リスク | 対処 |
|---|---|
| 「英語教室で理科？」の違和感 | CLIL は欧州で標準。論点を「発話量と語彙」に置く（U-Speak と同じ） |
| 先生が運営できない | 台本・投影モード・クイズ解説で設計済み。導入初月はオンライン研修（Premium） |
| 飽き（8週で終わる） | 第2ターム（太陽系探査・宇宙開発史・地球観測）を半年ごとに追加。年2ターム × 継続課金 |
| AI の誤答 | 事実は正典（missions.ts）に固定。AI は発話フィードバックと要約のみ。出典を UI に常時表示 |
| 外部API（ISS）停止 | 軌道モデルでフォールバック済み |
