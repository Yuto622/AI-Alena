# 私立小学校リスト：収集と採点のルール

目的：U-Speak Roblox（Roblox 上で遊びながら英語を学ぶ小学生〜高校生向け教材）の営業先として、
英語教育に力を入れている私立小学校を全国から洗い出し、順位をつける。

## 収集

- 都道府県（または東京都生活文化局など）が公表している「私立小学校一覧」を一次資料にして、漏れなく全校を拾う
- 各校の公式サイトで英語教育の情報を確認する
- **推測で埋めない**。確認できなかった項目は空欄にし、notes に「未確認」と書く
- 国立・公立・インターナショナルスクール（一条校でないもの）は対象外

## CSV の列（UTF-8、ヘッダーあり、カンマ区切り、値にカンマが入るときは "" で囲む）

```
pref,school_name,city,official_url,english_hours_low,english_hours_high,english_course,native_teacher,ict_device,philosophy,score,evidence_url,notes
```

- `english_hours_low`：低学年（1〜2年）の英語の週あたりコマ数（例：2）。不明なら空欄
- `english_hours_high`：高学年（5〜6年）の週あたりコマ数
- `english_course`：英語で授業をするコース・イマージョン・国際コースなどの名前。なければ空欄
- `native_teacher`：ネイティブ教員・英語専科教員の常駐が確認できれば `yes`
- `ict_device`：1人1台端末の種類（iPad / Chromebook / Windows / 不明）
- `philosophy`：建学の精神・理念を20字以内で（例：カトリック・国際人の育成）
- `score`：下の採点で 0〜10
- `evidence_url`：英語教育について確認したページの URL

## 採点（合計 10 点）

- 英語の授業：1年生から週2コマ以上 = 3、1年生から週1コマ = 2、高学年からのみ = 1、不明 = 0
- 英語で授業をするコース・イマージョン・国際コースがある = 3
- ネイティブ教員・英語専科が常駐 = 1
- 英検の目標・海外研修・英語行事（スピーチコンテスト等）がある = 1
- 1人1台端末（iPad / Chromebook など）が確認できる = 1
- 理念・教育目標に「国際」「グローバル」「世界」などがある = 1
